# ✈️ Pocket Game Hub (機上離線棋藝盒 8-in-1)

專為飛機環境、無網路情境設計的輕量級局域網多人在線棋藝合集。

主機手機（Android Termux）開啟 Wi-Fi 熱點後，同行朋友**完全免安裝任何 App**，只需連上熱點並掃描 QR Code，即可透過手機瀏覽器（Safari / Chrome）即刻連線開戰！

---

## 🎮 內建八大經典棋類

1. **🎯 五子棋 (Gomoku)**：15x15 經典棋盤、星位標記、五連珠獲勝發光動畫。
2. **⚪⚫ 黑白棋 (Reversi / Othello)**：8x8 棋盤、合法落子光圈提示、3D 翻子動畫、無子可走自動 Pass。
3. **🀄 中國象棋 (Xiangqi)**：9x10 楚河漢界、九宮格「米」字斜線、塞象眼/蹩馬腿/將帥照面規則判定、選子吃子瞄準。
4. **♟️ 西洋棋 (Chess)**：8x8 競賽級高對比深淺格子（1-8, a-h 座標標籤）、兵到底線自動升變皇后。
5. **⭐ 六角星跳棋 (Chinese Checkers / 波子棋)**：
   - 支援 **👥 2 人對戰 (180° 對攻)** 與 **👥 3 人大亂鬥 (120° 三足鼎立)**。
   - 各陣營目標基地染上專屬背景色（紅/綠/藍），目標一眼認出。
   - 內建 BFS 多段連續搭橋跳躍（連跳）演算法，點擊終點一跳到底！
6. **🟡🔴 重力四子棋 (Connect 4)**：
   - 7x6 經典直立落子控制台，真實重力下墜物理動畫。
   - 水平、垂直、兩條對角線四子連線判定。
7. **❌⭕ 終極井字棋 (Ultimate Tic-Tac-Toe)**：
   - 3x3 大九宮格內嵌 9 個小九宮格，深度策略燒腦。
   - 當前小格落子位置將指定對手下一步的大棋盤區域，支援 Free Move 自由落子！
8. **🧱 德國圍棋 (Blokus / 格格不入)**：
   - 支援 **👥 2 人極速雙雄 (14x14 Blokus Duo)** 與 **👥 4 人經典四方 (20x20 Classic)**。
   - 完整 21 種幾何多聯骨牌（Polyomino），支援 90° 旋轉與水平翻轉。
   - 經典規則：第一子踩起點、後續「角對角相連、嚴禁邊相鄰」！

---

## 🕹️ 三大遊玩模式

* **🌐 飛機熱點雙機/多機連線**：支援 2~4 人即時對弈與多人即時觀戰。
* **🪑 小桌板同機對戰 (Face-to-Face)**：手機平放桌板，支援多人輪流下子。
* **🤖 離線 AI 搜尋**：八款遊戲皆內建啟發式 AI，單人搭機隨時練習。

---

## 🔊 100% 離線音效與震動
* 採用純代碼 Web Audio API 合成木質落子聲、吃子清脆聲、彈珠落洞聲、重力下墜聲、方塊卡扣聲、獲勝號角。
* 支援手機觸控震動反饋。

---

## 🚀 快速啟動

### 啟動遊戲
```bash
./start.sh
# 或在 Termux 根目錄執行：./start-game.sh
# 或使用 npm start
```

### 關閉遊戲
```bash
./stop.sh
# 或在 Termux 根目錄執行：./stop-game.sh
# 或使用 npm stop
```

瀏覽器打開：`http://localhost:8080` (同行朋友連上熱點後掃描終端機 QR Code 即可進入)。
